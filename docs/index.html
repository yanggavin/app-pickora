Technical Support

If you have issues with drawing, sound, haptics, purchases, or app behavior, contact support with:

  • Device model and iOS/iPadOS version
  • App version
  • What you expected and what happened
  • Screenshots or screen recordings (if possible)

Email: support@pickora-app.newtree.tech

Common Help

  • No sound: Check Settings → Sound Effects and device mute state.
  • No vibration: Check Settings → Haptics and system haptic settings.
  • Purchase not showing: Use Restore Purchases in the paywall.
  • Language issues: Ensure app and system language are configured correctly.
